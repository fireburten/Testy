Installation

Install via your preferred package manager:

Terminal
$ npm install your-package # or with yarn$ yarn add your-package

Basic Usage

Import and initialise in your entry file:

JavaScript
import { createApp } from 'your-package'; const app = createApp({ config: 'value', debug: false, }); app.start();
⚠️ Note

Node.js 18 or higher is required. Run node --version to check.
